# Physics Equations BreakDowns

Easy, intuitive breakdowns of physics equations - with interactive visualization. A just-for-fun, non-profit project: free to use, no ads, no strings attached.

**Live site:** [dthuong00.github.io/physics-equations](https://dthuong00.github.io/physics-equations/)
